# BasedPyright Issues

## Background
I created and activated a Python `venv` and installed Django, then I created a new Django project.

## Issue
BasedPyright doesn't recognize installed Django package and also shows a lot of errors when `recommended` Type Checking Mode is selected.

## Reproduction
1. Clone the repository in a location of your choosing.
2. Create and activate a Python `venv` in the repo.
3. Install the packages from `requirements.txt` in `venv`.
4. Set the Type Checking Mode to `recommended` or `basic` in VS Code.
5. Get so many errors.
